# SE-Git-hw
## About
This project demonstrates Git and GitHub version control for CINS 5318.

## Files
- hello.py: Prints Hello World
- apple.py: Prints I eat apple

## How to Run
python hello.py
python apple.py

## Branches
- main: Primary branch
- feature-1: Added apple.py feature (merged)
- conflict-branch: Used to simulate merge conflict

## Issues and Resolutions
